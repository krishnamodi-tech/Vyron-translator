    🛠️ VYRON AI — Backend & Credentials Setup

    VYRON AI is architected to work in two distinct modes:

    🟢 AI Accelerated Mode

    Powered by Google Gemini 1.5 Flash on the FastAPI backend (main.py). Provides clause-by-clause legal breakdown and advanced contextual jargon extraction.

    🟡 Client Hybrid Mode

    Runs directly via live free translation endpoints, client-side Tesseract.js OCR, and Web Speech API. Completely functional even without cloud API keys!

    How to add a Gemini API Key:

    1. Get a free key from Google AI Studio.
    2. Open .env in this project and set GEMINI_API_KEY=your_key_here.
    3. Restart the backend server: python main.py.
